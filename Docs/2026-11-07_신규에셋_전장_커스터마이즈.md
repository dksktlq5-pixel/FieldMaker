# 신규 에셋 적용 기록

기준: 2026-11-07 / Unreal Engine 5.8.4 / D:/UnReal/FieldMaker

## 최종 확정 변경: 총기 축소·방탄복·효과

사용자 추가 지시에 따라 초기 36종 카탈로그를 **활성 총기 18종**으로 축소했다. 나머지 데이터와 에셋은 보존하고 bInCatalog=false로 비활성화했다. 서버도 비활성 총기 장착을 거부한다. 칼은 기본 3번 슬롯 무기이며 상점과 18종 집계에서 제외했다.

- 두 방탄복 모두 일반 총탄 피해의 50%를 흡수하고 흡수량만큼 방어력이 소모된다. 기존 머리·칼·폭발 우회 규칙을 유지한다. 외형 방탄복과 능력치는 별개다.
- 상점은 장비/권총/기관단총/라이플/저격소총/중화기/수류탄의 7열로 구분했다. 총기 18, 방탄복 2, HE 수류탄 1, 미구현 예정 투척물 4로 총 25개 카드다. 예정 항목은 비활성이다.
- 총구의 구형 메시를 없애고 교차 평면의 짧은 화염으로 변경했다. 주무기 길이 18cm, 권총 12cm, 표시 0.045초. Substrate Front Material 연결과 주간 노출에 맞는 발광값을 적용했다. 실제 발사 캡처에서 주황색 화염 확인.
- 칼 휘두르기 소리를 직접 만든 0.24초 바람 가르는 소리 A_FMKnifeWhoosh로 교체했다. 원래 A_FMMelee는 보존했다. 연결과 비무음 원본 파형은 확인했으나 실제 출력 청취는 미검증이다.
- PBR 의상·파생 무기·바닥 재질도 Substrate Shading Models 출력에 연결했다. 커스터마이즈 미리보기 조명의 푸른 색조는 남아 있어 중립 조명 조정이 필요하다.

## 남은 범위

- 카탈로그의 32개 행은 대표 모델을 공유한다. 총기 36종이 각자 고유한 실물 모델이라는 의미가 아니다. 개별 총기 에셋을 확보하면 행 단위로 교체해야 한다.
- 36종 전체의 연속 발사 자동검증은 도구 API 오류 및 동일 무기 재선택 시 기존 탄약을 유지하는 동작에 대한 테스트 가정 오류로 중단했다. 데이터 경로 확인과 대표 모델 검증을 전체 런타임 통과로 대체 표기하지 않는다.
- 두 번의 마스터 출력 녹음은 무음이다. 에셋 연결은 확인했지만 실제 청취·상대 거리별 출력·수류탄 원격 폭발음은 추가 확인이 필요하다. 실패한 녹음을 반복하지 않았다.
- FirstPersonRifleAnimations는 SK_Mannequin_Arms_Skeleton을 사용하고 현 Quantum 팔과 다르다. 기존 팔/IK 구조를 유지했으며 리타깃·전용 장전/발사 애니메이션 연결은 미완료다.
- 현재 전장은 테스트용 전장 프로토타입이다. 엄폐 충돌은 단순 박스이며 차량 창문/바퀴 등 정밀 충돌과 경쟁전 동선 밸런스 검증은 남아 있다.
- 상점은 CombatTest 무료 선택을 유지한다. 경제·구매 제한·정식 라운드 진행·건축 구현 완료로 처리하지 않는다.

## 에디터 확인 순서

1. /Game/Map/L_FMBridgeBattlefield 열기 → Listen Server, 플레이어 2명 PIE.
2. B 상점에서 AKS-74U / AS Val 선택 → 발사·R 재장전·ADS 확인.
3. C 커스터마이즈 → 모자/상의/바지/방탄복 색상 선택 → 적용 → 상대 화면 확인.
4. 좌우 통로 걷기·달리기·점프, 검문소 엄폐와 경계 충돌 확인.
5. 오디오 출력 장치와 PIE 포커스를 확인하고 실제 총소리/재장전/상대 발사음 청취.
6. 다음 구현: 전용 애니메이션 리타깃과 총기별 손가락/그립 시각 검수, 이후 경제·정식 라운드 연결.
