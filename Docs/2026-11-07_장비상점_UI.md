# FIELDMAKER 장비 상점 UI

2026-11-07 (한국 시간)

## 조작과 구성

- B: 상점 열기. 상점 안에서 B 또는 Esc, 우측 상단 닫기 버튼으로 닫는다.
- 보조 무기 / 소총 / 근접 무기 / 투척 무기 / 방어구 열과 우측 상세 패널을 제공한다.
- M4·권총·칼·수류탄·경량 방탄복 항목을 선택하면 녹색 강조와 상세 내용이 바뀐다.
- 보유 무기 장착 버튼은 기존 캐릭터의 서버 장착 RPC를 사용한다.
- 방탄복 착용/해제 버튼은 CombatTest에서만 동작한다. 그 외 단계에서는 비활성화한다.
- 상점을 열면 자동 사격·ADS·달리기를 중지하고 이동·시점 입력을 잠근다. 닫으면 게임 입력과 마우스 상태를 복구한다.
- UI는 창 크기에 맞춰 비율을 유지하며 축소한다. 무기 그림은 자체 제작한 간단한 도식 아이콘이다.

## 범위

이번 작업은 상점 UI와 기존 보유 장비·방탄복 테스트의 연결이다. 가격·잔액·실제 구매·장비 소유권·구매 구역 검사는 아직 연결하지 않았다. 화면에서도 보유 장비 테스트임을 표시한다. 추가 총기나 방어구를 실제 제공하는 것처럼 나열하지 않고 준비 중으로 표시했다.

주요 변경: FMShopWidget.cpp/.h, FMPlayerController.cpp/.h, FMShopTests.cpp. 기존 FMCharacter·입력·무기·DataTable 구조를 재사용한다.

## 중간 검증 오류와 수정

처음 추가했던 FieldMaker.Shop.KeyboardAndFocus 에디터 자동 테스트는 시작 전에 PIE가 종료되는 엔진 동작과 충돌했다. 이 때문에 필요한 2인 PIE가 없다는 테스트 오류가 Message Log에 나타났다. 해당 자동 테스트 등록을 제거하고, 기존 PIE 세션 내부에서 실행하는 개발용 fm.Shop.VerifyKeyboard 명령으로 교체했다. 게임 실행을 종료하는 테스트 경로를 사용하지 않는다.

computer-use 창 캡처는 FrameArrived/window capture timed out으로 실패해 중단했다. 화면은 Unreal MCP capture_image로 확인하고, 키 처리는 실제 Slate 이벤트 경로를 통해 검증했다.
