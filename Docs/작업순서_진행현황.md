완료 해석 주의:
- 체력/공격 코드 존재는 기획의 전투 전체 완료를 뜻하지 않는다. 전체 처치·라운드 연동 검증은 남았다.
- HUD 상단 숫자는 `FMCombatHUD.cpp`에서 팀 인원수를 세어 표시한다. 라운드 승점이 아니다.
- 커스터마이즈는 현재 파츠 착용/해제 중심이다. 여러 모자·티셔츠·몸 선택 기능은 없다.
- 1인칭 팔은 전신과 별개인 고정 외형이다. 향후 외형 확장 시 1인칭 팔과 소매 대응 규칙이 필요하다.
- 칼/라이플 액션은 C++ 절차적 보정이며 전용 제작 애니메이션 클립을 확보한 상태가 아니다.
- 방탄복 외형과 피해 흡수 시스템은 별개다. 소모형 방어력과 유무·피해 감소·복제는 구현했고, 실제 구매/라운드 장비 정산은 남았다.
- 메뉴의 무기고·구조물 도감·상점 버튼은 로그 출력 수준이며 실제 콘텐츠 화면이 아니다.
- Listen Server 2인 PIE는 Dedicated Server 검증을 대체하지 않는다.
- Fab 추가 다운로드는 수행하지 않았다. 요청에 따라 중단했다.

## 앞으로 실제 진행할 순서

1. **02 규칙과 MVP 확정**: 칼전 승점/반복, 일반전 전멸/거점 채택, 무승부·시간 경계, 구축 단계 설치, 진영 교체 초기화. 초안 제안과 사용자 확정을 구분해 기록한다.
2. **03~04 서버 기반 보완 (로컬 리슨 우선으로 변경)**: GameState/PlayerState 데이터 소유권, 서버 타깃과 빌드 가능 환경 확인, 로컬 리슨 서버 호스트+참가자 팀 스폰. 전용 서버 타깃·접속 검증은 이후 진행. 엔진 변경 필요성은 환경 확인 후 판단한다.
3. **05·07 전투 MVP 마감**: 달리기/장착/사망 중 공격 제한, ADS, 칼·M4 데이터, 방탄복 공식, 수류탄, 일치하는 체력/탄약/사망 결과. 사용자 요청으로 CS 계열 총기 34종 테스트 데이터·상점 확장을 선행했고, 정식 모델/전용 모션은 남았다.
4. **06·08 경기 흐름**: 칼전→일반 라운드 상태와 타이머, 피해 허용 시점, 부활, 전멸/시간 종료, 관전, 5승 진영 교체 1회와 10승 종료. 중앙 거점은 채택 확정 시 포함한다.
5. **09 건설 MVP**: 모래주머니와 방탄벽. 개발용 수량으로 설치/파괴/유지 검증 후 경제에 연결한다.
6. **10 구매·경제 연결**: 구매 단계/스폰 구역 검사, 자금/수량/가격/보상, 구매·설치 중복 요청 방지, 생존과 진영 교체 정산.
7. **11 첫 MVP 통합 테스트**: 맵 1개, 전용 서버 1v1, 실제 10승까지 전체 흐름과 지연/패킷 손실·이탈·성능 검증.
8. **12~14 확장**: 전력/포탑, 3v3→5v5, 추가 총기/투척/이동 구조물, 메뉴/옵션 완성, 외형 확장, 성장·출시 준비.
