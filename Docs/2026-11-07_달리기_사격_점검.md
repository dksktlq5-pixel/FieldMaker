# 달리기와 테스트 맵 사격 점검

기준일 2026-11-07. 기존 전투·걷기 보정 및 전장 테스트 맵 작업의 후속 점검이다.

## 발견한 원인과 수정

1. Quantum A_MM_Run_Fwd에는 1.9초 동안 약 1,010cm의 루트 이동이 있다. CharacterMovement 이동과 별도로 전신 포즈가 밀리면서 메시에 상대 배치된 무기와 팔 IK가 분리됐다. 원본을 보존하고 A_FMRun_InPlace를 생성해 루트 모션을 끄고 ForceRootLock을 활성화했다. AnimBP의 Run 참조만 교체했다. 교체 전 AnimBP도 별도 백업했다.
2. 루트 이동을 제거한 뒤에도 정지 조준 위치를 달리기에 그대로 사용해 상체가 어색했다. 달릴 때 총을 몸 가까이 낮춰 들도록 월드/1인칭 무기 자세를 보간했다. 점프·낙하·착지 클립은 교체하지 않았다.
3. READY 상태에서 공격을 차단한 상태로 테스트 맵이 대기해 좌클릭 사격이 막혔다. GameMode의 CombatSandbox를 테스트 맵에서만 켜고 CombatTest 상태를 추가했다. 정식 준비·구매·구축·결과 단계의 공격 제한은 유지한다.
4. 1인칭 조준 시 임시 총기 모델의 개머리판이 카메라 가까이 들어왔다. 조준 중 무기를 앞으로 옮겨 근접 클리핑을 줄였다.

## 함께 반영된 범위

- 서버의 달리기·장착·재장전·사망·준비 상태 공격/ADS 제한과 상태 복제.
- 우클릭 ADS, FOV 90→65 보간, 조준 감도 배율, 유지/토글 설정 필드와 저장 연결.
- 기본 걷기 250cm/s, 걷기 클립 속도 연동. 점프 중 손 흔들림 감쇠 및 지상 이동 거리 기반 흔들림.
- 중앙/측면 엄폐물, 컨테이너·벙커·외벽·팀 스폰 바닥과 도로 표시를 배치한 고정 블록아웃.
- 하늘·구름·태양·스카이라이트·안개·낮 노출과 재질 색상. 모션 블러 0, 낮 조명용 캐시 노출 범위 조정.

## 확인한 결과

- 실제 좌클릭이 활성 참가자 PIE 창에 전달되어 탄약 30→26 감소, 상대에게 피해·사망 발생 확인.
- 서버/클라이언트 공격 차단, 조준·달리기 상호 배제, 재장전 중 공격 금지, 장착 중 공격 금지, 칼 ADS 금지, 체력 및 사망 복제 검사 통과.
- 걷기 250cm/s 구간에서 실제 시퀀스 플레이어 속도 1.25배 확인.
- 상대의 달리기 전신에서 루트 이탈 0cm와 오른손·무기 그립 밀착 확인. 마지막 달리기 자세 측정 234 Run 프레임, 속도 550cm/s.
- 달리기 후 정지 및 Jump→Fall→Land 회귀 확인.

## 사용 방법과 남은 작업

L_FMLocalMatchTest에서 PIE를 Play As Listen Server, 플레이어 2명으로 실행한다. HUD의 FIRE TEST는 정식 경기 진행 대신 사격 검증이 가능한 개발 상태다. 사망 후 새 플레이어를 보려면 현재는 PIE를 다시 실행한다. 다음 라운드 부활과 승패 진행은 아직 연결하지 않았다.

총기와 엄폐물은 임시 테스트 모델이다. 무기별 전용 제작 애니메이션, 방향별 전술 이동 클립과 정밀한 조준기 형상은 후속 범위다. 고정 엄폐물 배치는 구매/건설/파괴 시스템의 완료를 뜻하지 않는다. ADS 설정의 저장·취소·기본값은 기존 설정 구조에 연결했으며, 전체 설정 UI의 재실행 저장 검증은 별도 항목으로 남긴다.

다음 기능 작업은 칼·M4 데이터화와 부위 피해·방탄복 공식이다. 이후 칼전/일반 라운드/관전과 건설·경제 순서로 진행한다.
