## 남은 범위

현재 손 동작은 절차적 IK·손가락 변형이다. 무기별 전용 애니메이션 클립을 새로 제작하거나 라이플 전용 스켈레톤을 Quantum에 리타깃한 결과는 아니다. 전용 재장전·볼트·슬라이드 조작의 정밀한 연출은 별도 애니메이션이 필요하다.

18종은 카탈로그 수이며 서로 다른 원본 모델 18개를 뜻하지 않는다. 권총 5종은 Police Pistol, 일부 기관단총은 MP5, Negev/M249는 대표 모델을 공유한다. AR15는 기존 M4 논리 ID를 유지하며 AR70는 ASVAL을 대체해 활성 라이플 3종을 유지한다. Ghoul은 기존 SSG08 논리 ID에 연결했다.

AWP형 원본은 텍스처 없는 WorldGrid 상태여서 파생 메시의 무광 재질로 보완했다. 전용 PBR 텍스처는 추가로 필요하다. 손바닥 접촉 수치 통과는 모든 프레임의 피부 관통이 없음을 보증하지 않는다. 칼·투척의 전체 동작 및 모든 무기의 이동 프레임에 대한 시각 검수는 별도 회귀 항목이다. 이번 작업에서 실제 출력 사운드 청취는 검증하지 않았다.
