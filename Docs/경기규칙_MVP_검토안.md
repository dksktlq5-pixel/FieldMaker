# FIELDMAKER 경기 규칙과 첫 MVP 검토안

작성일: 2026-11-06. 상태: 사용자 승인으로 규칙과 MVP 범위 확정. 구현 완료를 뜻하지 않는다.
근거: `FieldMaker 기획서.docx` 및 `FIELDMAKER_v2_작업사항_세부기획서.docx`.
원본 문서와 현재 게임 코드는 변경하지 않았다.

## 유지하는 기획 방향

- 최종 5v5, 첫 개발·검증은 로컬 리슨 서버 1v1·맵 1개. 로컬 전용 서버 검증은 후속 진행.
- 10승 선취. 한 팀이 처음 5승에 도달하면 진영을 교체한다.
- 진영 교체는 경기당 한 번이며 팀과 승점은 유지하고 스폰 방향을 교환한다.
- 첫 라운드는 칼전. 2라운드부터 구매와 구축을 진행한다.
- 전투 중 부활하지 않고 다음 라운드 시작 시 부활한다.
- 생존 구조물은 일반 라운드 사이에 유지하며 진영 교체 시 제거한다.
- 서버가 피해·설치·구매·승패를 판정한다. 외형은 능력치에 영향을 주지 않는다.

## 확정을 요청하는 권장안

| 항목 | 권장 규칙 | 이유 |
|---|---|---|
| 칼전 | 경기 시작 한 번, 승리 시 승점 1 포함, 진영 교체 후 반복 없음 | 세부기획 기본안을 유지하고 경기 흐름 단순화 |
| 칼전 시간 | 준비 10초 / 전투 60초 / 결과 10초 | 원문 제안 수치로 테스트 시작 |
| 칼전 시간 종료 | 생존 인원 → 생존자 체력 합 비교, 모두 같으면 무승부 | 소극적 회피만으로 동률을 깨지 못하도록 명확한 비교 기준 제공 |
| 일반전 목표 | 전멸 또는 후반 중앙 거점 점령 | 원문의 추가 제안을 채택해 엄폐 후 무한 대기를 줄임 |
| 일반전 시간 | 구매 20초 / 구축 30초 / 복귀·잠금 3초 / 전투 150초 / 결과 10초 | 원문 제안 유지, 복귀 잠금은 구축 뒤 별도 구간 |
| 중앙 거점 | 전투 시작 90초 뒤 활성화, 단독 팀이 10초 연속 점령하면 승리 | 끝까지 교전할 이유 제공 |
| 점령 중 적 진입 | 진행을 정지, 점령 팀이 전원 이탈하면 0으로 초기화 | 원문의 점령 방식 유지 |
| 일반전 시간 종료 | 승리 조건 미달이면 무승부. 생존자 수/체력으로 승리시키지 않음 | 칼전과 일반전 시간 종료 규칙 구분 |
| 무승부 | 양 팀 승점 변화 없음, 라운드 번호 증가, 일반전 보상은 패배와 동일 | 라운드 번호와 승점을 별도 유지 |
| 건설 | 구축 단계의 자기 팀 구역에서만 설치. 구매·전투·결과 중 설치 금지 | 전투 중 즉석 방벽 생성과 구매/설치 경합 방지 |
| 경계와 피해 | 구매·구축은 중앙 경계 통과 및 피해 금지 | 준비 단계 안전 보장 |
| 아군 피해 | 비활성. 자신이 던진 수류탄의 자해는 허용 | 원문 MVP 제안 유지 |
| 참가·이탈 | 진행 중 접속은 관전 대기, 다음 라운드 참가. 1v1 한 명 이탈 시 무효 종료 | 승패·보상 악용 없이 테스트 종료 |

## 상태별 허용 행동

표의 이동·구매·건설·공격은 생존한 플레이어 기준이다. 사망자는 모든 게임 행동을 차단하고 아군 관전만 허용한다. 메뉴와 설정 조작은 경기를 정지시키지 않는다.

| 상태 | 이동 | 구매 | 설치 | 공격·피해 |
|---|---|---|---|---|
| 접속 대기 | 금지 | 금지 | 금지 | 금지 |
| 칼전 준비 | 팀 준비 구역 안 | 금지 | 금지 | 금지 |
| 칼전 전투 | 허용 | 금지 | 금지 | 칼만 허용 |
| 일반전 구매 | 팀 스폰 구역 안 | 스폰 안에서만 | 금지 | 금지 |
| 구축 | 자기 팀 경계 안 | 금지 | 허용 구역만 | 금지 |
| 복귀 카운트다운 | 스폰으로 복귀 후 잠금 | 금지 | 금지 | 금지 |
| 일반전 전투 | 허용 | 금지 | 금지 | 허용 |
| 결과·진영 교체·경기 종료 | 잠금 | 금지 | 금지 | 금지 |

달리는 동안 공격·ADS 금지, 장착 중 공격 금지. 건설 모드와 공격은 동시에 실행하지 않는다. 단계 변경 시 프리뷰·진행 중 공격/재장전/투척을 취소하고 이미 생성된 투사체도 새 상태의 피해 허용 규칙을 따른다.

## 경계 상황 판정 권장안

모든 시간은 서버 기준이다. 전투 유효 구간은 `StartTime <= EventTime < EndTime`이며 종료 시각과 같은 공격·점령 완료는 인정하지 않는다. 클라이언트가 보낸 과거 시각만으로 유효 판정을 바꾸지 않는다. 지연 보정은 별도 정책으로 다룬다.

1. 유효한 피해를 처리한 후 같은 서버 판정 주기에 모인 결과를 한 번만 평가한다.
2. 양 팀 동시 전멸이면 무승부.
3. 한 팀 전멸이면 살아 있는 팀 승리.
4. 전멸이 없고 유효 시각 안에 거점 점령이 완료되면 점령 팀 승리.
5. 그 외 종료 시각 도달 시 칼전은 인원/체력 비교, 일반전은 무승부.

전멸과 점령이 같은 판정 주기에 겹치면 전멸 판정을 우선한다. 판정 주기란 서버 게임 루프의 동일한 결과 평가 묶음이며 넓은 임의 시간창을 추가하지 않는다. 결과 확정 이후의 피해·점수·보상 요청은 무시한다.

## 라운드 유지와 초기화

| 시점 | 처리 |
|---|---|
| 칼전 종료 | 전원 자금 5,000 설정. 별도 칼전 처치 보상 없음. 다음 라운드 기본 칼 |
| 일반전 다음 라운드 | 전원 체력 100, 생존자의 총기·잔여 방탄복·미사용 투척류 유지, 총기 탄약 보충 |
| 일반전 사망자 | 구매 장비 상실, 다음 라운드 기본 칼. 미설치 구조물 수량은 유지 |
| 일반전 구조물 | 소유자 생사와 관계없이 위치·방향·남은 체력 유지 |
| 첫 5승 진영 교체 | 팀·승점 유지, 스폰 교환. 장비·보유 구조물·설치 구조물 초기화, 칼 지급, 자금 5,000 |
| 10승 | 경기 결과 화면. 경기 자금·장비는 영구 성장과 분리 |

일반전 승리 +4,000 / 패배·무승부 +2,500 / 적 처치 +300 / 개인 자금 상한 12,000은 테스트용 권장값이다. 진영 교체 초기화가 걸린 라운드는 최종 잔액 5,000으로 설정하며 이전 보상이 이후에 덧붙지 않게 한다.

## 첫 MVP 범위

포함: 전용 서버 1v1, 맵 1개, 칼·M4·방탄복·수류탄, 모래주머니·방탄벽, 최소 구매창/HUD/설정/아군 관전, 중앙 거점(권장안 채택 시), 구조물 유지·진영 교체·10승 종료.

후속: 3v3/5v5, 추가 맵·총기·연막·섬광, 전력·포탑·센서·이동 구조물, 완성형 로비·도감·성장·추가 의상. 이미 구현한 권총은 보존하되 MVP 검증의 필수 범위를 늘리지 않는다.

MVP 전투에 필요한 피해량·반동·방탄복 공식과 구조물 가격·체력·경사·수량 제한은 각 구현 직전 별도 수치표에서 확정한다. 이번 규칙 승인만으로 그 수치까지 확정하지 않는다.

## 규칙 검증 사례

| 사례 | 기대 결과 |
|---|---|
| 칼전에서 상대만 전멸 | 승점 +1, 결과 후 자금 5,000, 일반전으로 전환 |
| 칼전 종료 때 인원 같고 체력 합 차이 | 체력 합이 큰 팀 승리 |
| 칼전 종료 때 인원·체력 합 모두 같음 | 무승부, 칼전 반복 없이 2라운드 |
| 일반전에서 둘 다 생존한 채 제한 시간 종료 | 무승부 |
| 동일 판정 주기 양 팀 전멸 | 무승부, 점수·보상 중복 없음 |
| 전투 89초 | 거점 비활성 |
| 활성 거점 단독 10초 완료가 종료 시각 이전 | 점령 팀 승리 |
| 적 진입 후 점령 팀 모두 이탈 | 진행 정지 후 0 초기화 |
| 종료 시각과 정확히 같은 공격 또는 점령 완료 | 유효 전투 이벤트로 인정하지 않음 |
| 전투 중 설치 요청·구축 중 구매 요청 | 거부, 자금·수량 보존 |
| 처음 한 팀 5승 | 진영 교체 1회, 구조물 제거, 점수 유지 |
| 교체 이후 상대도 5승 | 두 번째 진영 교체 없음 |
| 어느 팀 10승 | 경기 종료, 다음 라운드 생성 없음 |

이 표는 예정 테스트 사례이며 실행 통과 기록이 아니다.
