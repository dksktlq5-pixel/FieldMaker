## 적용 범위

사용자가 제공한 CS 구매 화면을 기준으로 어두운 반투명 배경, 금색 도식 아이콘, 세로 격자 목록, 우측 캐릭터 미리보기와 장비 상세 패널을 적용했다. 장비 / 권총 / 기관단총 / 소총·저격소총 / 중화기 / 수류탄 6열이며 각 열은 독립 스크롤을 지원한다. B로 열고 B·Esc로 닫는다. 마우스를 올리면 상세가 바뀌고 클릭하면 테스트 장착한다.

현재는 모든 진영에서 사용할 수 있는 테스트 카탈로그다. 가격은 참고값이며 실제 자금 차감·구매 구역·구매 시간·진영별 판매 제한·무기 드롭/습득·반환은 아직 연결하지 않았다. 현재 규칙과 가격/피해 수치는 FieldMaker 초기 테스트값이며 CS:GO의 모든 수치와 특수 동작을 그대로 재현한 것은 아니다.

## 동작과 데이터

- 기존 1 주무기 / 2 보조무기 / 3 칼 / 4 투척 슬롯 유지. 여러 총기를 위한 중복 캐릭터·입력 시스템을 만들지 않았다.
- 각 총기의 이름·종류·참고 가격·피해·탄창·예비탄·발사 간격·자동/단발·재장전·확대 FOV를 DT_FMWeapons에서 읽는다.
- 주무기/보조무기의 총기 ID를 서버에서 검증하고 다른 클라이언트에도 복제한다. 기존 부위 피해·소모형 방탄복을 유지한다.
- 샷건은 서버에서 한 번의 탄약 소비로 여러 개의 분산된 히트스캔 탄환을 처리한다.
- 저격총과 AUG/SG 553은 데이터별 확대 FOV를 사용한다. 전용 스코프 렌즈·망원 조준경 그래픽까지 구현한 것은 아니다.
- 같은 총기를 다시 선택해도 탄약을 보충하지 않는다. 다른 총기로 무료 교체하는 기능은 CombatTest에서만 허용하며 실제 전투/구매 단계에서는 차단한다.
- 기존 커스터마이즈 미리보기를 재사용하고 상점용 노출/하늘 표시 옵션을 추가했다. 미리보기 캐릭터는 복제하지 않으며 창을 닫으면 캐릭터·카메라·조명을 정리한다.

## 외형·애니메이션의 실제 상태

7개의 파생 임시 메시를 추가했다: SMG, Sniper, Shotgun, LMG, AK, Suppressed, HeavyPistol. 기존 라이플·권총 임시 메시를 복제해 형태를 구분하고, 기존 손 그립 좌표를 유지했다. 원본 메시를 덮어쓰지 않았다. 저격총·소음기 파생 모델은 총구 섬광 위치도 조정했다.

각 총기의 정식 모델 34개를 확보한 상태는 아니다. 카탈로그 도식 아이콘도 종류별 공통 아이콘이다. 손·장전·사운드는 기존 계열 동작을 재사용한다. Dual Berettas 양손 독립 표현, R8 충전, Glock/FAMAS 점사 모드, 샷건 한 발씩 장전, 소음기 탈부착, 개별 반동 패턴/관통 등은 미구현이다. 원본 애니메이션과 기존 Quantum 스켈레톤을 보존했다.

기존 DT_FMWeapons는 /Game/FieldMaker/Backups/DT_FMWeapons_PreCatalog_20261107에 백업했다.
